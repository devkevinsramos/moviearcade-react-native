# Capturas para a entrega

Depois dos testes no Expo Go no iPhone, registre as quatro telas reais:

- `login.png` — tela de Login.
- `home.png` — tela inicial após autenticação.
- `sobre.png` — informações do MovieArcade e Toolbar Sobre.
- `contato.png` — dados institucionais e Toolbar Contato.

Adicione os quatro arquivos nesta pasta e envie junto com o projeto no GitHub. Não utilize imagens simuladas como se fossem capturas da aplicação executada.
